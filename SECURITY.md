# Security

## Reporting a vulnerability

Please do not publish exploit details in a public issue.

Use GitHub private vulnerability reporting when it is available for this repository. If it is not available, open a brief issue asking the maintainers for a private reporting channel. Do not include sensitive details in that issue.

Include the affected version, impact, reproduction steps, and any suggested mitigation in the private report. You should receive an acknowledgement within five business days.

## Supported versions

Security fixes are provided for the latest released minor version. Pre-release builds are supported on a best-effort basis until the first public release.

## Safe use

Source Twin reads repository files and invokes Git and the bundled structural inventory tool. Review an untrusted repository before running development tools inside it.
