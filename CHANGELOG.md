# Changelog

Notable changes to Source Twin are recorded here.

## Unreleased

### Added

- A publishable npm CLI with `init`, `check`, and `coverage`.
- Plain-language logic files, shared terms, source mappings, and strict schema validation.
- Structural code and test coverage across the first supported languages.
- Git-aware review against an explicit branch, tag, or commit.
- Equivalent text and JSON output with offline reference help.
- A portable, agent-neutral Source Twin skill.
- Cross-platform CI, package smoke tests, and Source Twin's own repository mirror.
- A local product website with a substantial interactive example.
